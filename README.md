# Full Web Capture Enhanced（网页整页截图增强版）

🚀 **一款可靠的 Chrome 整页截图扩展**

## ✨ 核心功能

- **📸 整页截取** — 稳定截取文档主滚动区域
- **🎨 现代化界面** — 实时进度条与加载动画
- **⚙️ 高级选项** — PNG/JPEG 格式、质量控制、超时设置
- **🛡️ 可靠错误处理** — 单帧确认、限速与失败重试
- **🌐 多语言** — 支持中文和英文界面
- **✂️ 图片裁剪** — 内置裁剪工具，可精确编辑
- **📋 一键复制** — 截图直接复制到剪贴板
- **🎯 快速处理** — 为速度与稳定性优化

## 🚀 安装方法

### 方式一：开发者模式加载（推荐）
1. 下载或克隆本仓库
2. 打开 Chrome → **扩展程序**（`chrome://extensions/`）
3. 开启右上角的**开发者模式**
4. 点击**加载已解压的扩展程序**
5. 选择本扩展所在文件夹
6. 将扩展固定到工具栏

### 方式二：手动安装
1. 下载扩展文件
2. 解压到任意文件夹
3. 按方式一的步骤加载

## 🎯 使用方法

1. **打开**任意网页
2. **点击扩展图标**或按快捷键 `Alt+Shift+P`
3. **等待进度条**实时更新
4. 在**新标签页中查看结果**
5. 按需**下载、复制或裁剪**

## ⚙️ 配置说明

点击弹窗中的 **⚙️ Config** 可自定义：

- **格式**：PNG（高质量）或 JPEG（体积小）
- **质量**：JPEG 压缩级别（10-100%）
- **超时、重试、平滑滚动、图片等待与重叠率**：均会在下一次截图实际生效
- **语言**：中文 / 英文切换

## 🔧 高级特性

- 截取失败**智能重试**
- 失败分区自动重试，避免静默漏图
- **裁剪工具**支持拖拽调整选区
- 多种下载格式（PNG、JPEG、WebP、PDF）
- 自定义保存位置
- 深色 / 浅色主题切换

## 🌐 多语言支持

- **English** — 默认界面语言
- **中文** — 完整中文翻译
- 点击弹窗中的 🌐 按钮切换语言

## 📱 兼容性

- **浏览器**：Chrome 88 及以上
- **页面类型**：HTTP、HTTPS、本地文件
- **页面尺寸上限**：宽 / 高各 50,000 像素
- **限制**：无法截取 chrome:// 等浏览器内置页面

## 🐛 常见问题

- **超长页面**：页面主滚动区域最大支持 50,000 像素；可增加超时时间
- **权限报错**：刷新页面后重试
- **复制失败**：请使用支持 Clipboard API 的现代浏览器

## ⚠️ 当前边界

- 支持文档主滚动区域；独立滚动面板、虚拟列表和无限滚动内容不会被自动展开。
- 截取期间请保持目标标签页处于活动状态，避免浏览器截图到其他标签页。
- 可使用 `npm test` 与 `test/fixtures/long-page.html` 执行回归检查，详见 [TESTING.md](TESTING.md)。
